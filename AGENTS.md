# AGENTS.md

Before any change, read `DESIGN.md` (architecture) and `Spec.md` (requirements). Follow both. If they conflict, stop and ask.

Before acting on a task:
1. Read every `.agents/skills/*/SKILL.md`.
2. Apply the relevant skills' workflows and validation. Don't force unrelated skills onto a task.
3. Re-read the docs and re-scan the skills when scope changes or a skill is added.

If skills conflict, follow the more specific task guidance and repo requirements. Ask only if the conflict blocks safe progress.
